# Hytale Formats Wiki

This is an **Unofficial** Hytale wiki documenting all of the games external file formats.

---

## About

This repository stores information relating to the file formats used by the game [Hytale](https://hytale.com/), from the world format, entity format, player data format, etc.

View the source repo [here](https://github.com/BJTMastermind/hytale-formats-wiki) and see the `docs` folder for the documentation.
